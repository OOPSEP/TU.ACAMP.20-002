# เกณฑ์การให้คะแนนความมีนัยสำคัญ Scope 3 (Fr-03.2) — ACAMP Weighted Scoring v1.0

> **สถานะเอกสาร**: เกณฑ์ภายในของระบบ ACAMP ออกแบบเมื่อ 2026-09-17
> **ข้อเท็จจริงที่ต้องระบุในรายงาน**: เทมเพลต TCFO_R_01 v07 ของ อบก. กำหนด *หัวข้อที่ต้องพิจารณา* ไว้ 6 ข้อ แต่ **ไม่ได้กำหนดน้ำหนัก สูตรรวม หรือเส้นตัด** ใด ๆ และเปิดช่อง A35 ให้องค์กร "อธิบาย หลักเกณฑ์ในการประเมินความมีนัยสำคัญ" ด้วยตนเอง เกณฑ์ชุดนี้จึงเป็นดุลพินิจขององค์กร ไม่ใช่สูตรที่ อบก. ประกาศ แนวคิดอ้างอิงจาก ISO 14064-1:2018 (Annex H) และ GHG Protocol Corporate Value Chain (Scope 3) Standard ซึ่งให้น้ำหนักกับ *ขนาดการปล่อย* และ *อำนาจในการลด* มากที่สุด

## 1. โครงสร้างคะแนน

ทุกหัวข้อให้คะแนนเป็นระดับ **1–5 แบบบังคับเลือก** (dropdown ไม่ให้พิมพ์ตัวเลขอิสระ) คะแนนเต็ม 5.00

| หัวข้อ | คอลัมน์ในฟอร์ม | น้ำหนัก | ที่มาของคะแนน |
|---|---|---|---|
| Magnitude (ขนาดการปล่อย) | D | **30%** | ระบบคำนวณจากข้อมูลกิจกรรมจริง |
| Level of influence (อำนาจในการลด) | E | **20%** | ผู้ใช้เลือก |
| Risk or opportunity (ความเสี่ยง/โอกาส) | F | **20%** | ผู้ใช้เลือก |
| Sector guidance (แนวทางรายสาขา) | H | **15%** | ผู้ใช้เลือก |
| Outsourcing (การจ้างภายนอก) | K | **10%** | ผู้ใช้เลือก |
| Employee engagement (การมีส่วนร่วมของพนักงาน) | N | **5%** | ผู้ใช้เลือก |
| **รวม** | | **100%** | |

**สูตร**

```
คะแนนถ่วงน้ำหนัก = Σ (น้ำหนักหัวข้อ i × ระดับคะแนนหัวข้อ i) ÷ Σ (น้ำหนักหัวข้อที่ให้คะแนนแล้ว)
```

ตัวหารเป็นผลรวมของน้ำหนัก *เฉพาะหัวข้อที่เลือกไว้แล้ว* (normalize) เพื่อไม่ให้หมวดที่ยังให้คะแนนไม่ครบถูกกดคะแนนต่ำเกินจริง ระบบจะติดป้าย `incomplete` กำกับไว้แทน

## 2. เหตุผลของน้ำหนัก

- **Magnitude 30%** — เป็นหัวข้อเดียวที่วัดได้เป็นตัวเลขจากข้อมูลจริง ตรวจสอบย้อนกลับได้ จึงให้น้ำหนักสูงสุด แต่ไม่เกิน 1 ใน 3 เพื่อไม่ให้กลายเป็นเกณฑ์เดียวที่ตัดสิน
- **Level of influence + Risk 40% รวมกัน** — สองข้อนี้คือสิ่งที่ตัดสินว่าการรายงานหมวดนั้น *นำไปสู่การลดได้จริงหรือไม่* ตรงกับเจตนารมณ์ของ ISO 14064-1 Annex H
- **Sector guidance 15%** — เป็นเกณฑ์ภายนอกที่กำกับความสอดคล้องกับอุตสาหกรรม แต่ไม่ควรมีน้ำหนักเกินเกณฑ์ที่วัดจากข้อมูลขององค์กรเอง
- **Outsourcing 10% / Employee engagement 5%** — เป็นเกณฑ์เสริมเชิงโครงสร้างองค์กร มีผลต่อการตัดสินน้อยที่สุด แต่ต้องมีไว้ให้ครบตามฟอร์ม

## 3. ตารางระดับคะแนน

**Magnitude (D)** — ระบบให้คะแนนอัตโนมัติ โดยอิงเกณฑ์นัยสำคัญ **T** ที่องค์กรประกาศไว้ในหน้า Setup (ค่าเริ่มต้น T = 5%)

| ระดับ | เงื่อนไข | ตัวอย่างเมื่อ T = 5% |
|---|---|---|
| 1 | < 0.2T | < 1% |
| 2 | 0.2T – < T | 1% – < 5% |
| 3 | T – < 2T | 5% – < 10% |
| 4 | 2T – < 4T | 10% – < 20% |
| 5 | ≥ 4T | ≥ 20% |

**Level of influence (E)**

| ระดับ | นิยาม |
|---|---|
| 1 | ไม่มีอำนาจควบคุม และไม่มีข้อมูลจากคู่ค้า |
| 2 | มีข้อมูลบางส่วน แต่ยังลดไม่ได้จริงในทางปฏิบัติ |
| 3 | ต่อรองผ่านสัญญาหรือข้อตกลงได้บางส่วน |
| 4 | กำหนดเงื่อนไขจัดซื้อหรือปฏิบัติการได้โดยตรง |
| 5 | ควบคุมได้เต็มที่ ลดได้ภายในรอบรายงานถัดไป |

**Risk or opportunity (F)**

| ระดับ | นิยาม |
|---|---|
| 1 | ไม่มีผลต่อความเสี่ยงหรือโอกาสทางธุรกิจ |
| 2 | มีผลทางอ้อม ระยะยาว |
| 3 | มีผลต่อชื่อเสียง หรือข้อกำหนดของลูกค้าบางราย |
| 4 | มีผลต่อกฎระเบียบหรือต้นทุน (เช่น CBAM ภาษีคาร์บอน) หรือข้อกำหนดของลูกค้าหลัก |
| 5 | เป็นเงื่อนไขทางธุรกิจที่มีผลทันที (แพ้ประมูล เสียลูกค้า หรือผิดกฎหมาย) |

**Sector guidance (H)**

| ระดับ | นิยาม |
|---|---|
| 1 | ไม่ถูกกล่าวถึงในแนวทางรายสาขา |
| 2 | กล่าวถึงเป็นทางเลือก |
| 3 | แนะนำให้รายงานหากมีข้อมูล |
| 4 | แนะนำอย่างชัดเจนสำหรับอุตสาหกรรมนี้ |
| 5 | เป็นหมวดบังคับหรือหมวดหลักตามแนวทางรายสาขา หรือข้อกำหนด อบก. |

**Outsourcing (K)**

| ระดับ | นิยาม |
|---|---|
| 1 | ไม่มีการจ้างภายนอกในกิจกรรมนี้ |
| 2 | จ้างภายนอกเป็นครั้งคราว ไม่ใช่กิจกรรมหลัก |
| 3 | จ้างภายนอกประจำ แต่เป็นกิจกรรมสนับสนุน |
| 4 | จ้างภายนอกในกิจกรรมหลักบางส่วน |
| 5 | กิจกรรมหลักของธุรกิจถูกจ้างภายนอกทั้งหมด |

**Employee engagement (N)**

| ระดับ | นิยาม |
|---|---|
| 1 | พนักงานไม่เกี่ยวข้อง |
| 2 | เกี่ยวข้องทางอ้อม สื่อสารได้ยาก |
| 3 | สื่อสารหรือรณรงค์ได้ แต่ยังไม่มีตัวชี้วัด |
| 4 | มีโครงการมีส่วนร่วมพร้อมตัวชี้วัด |
| 5 | พนักงานมีส่วนร่วมโดยตรงและวัดผลได้ |

## 4. กฎการตัดสิน

1. หมวดที่ **ไม่มีแหล่งปล่อย** (ไม่ติ๊ก Has source) — ไม่ประเมิน ไม่คิดคะแนน
2. คะแนนถ่วงน้ำหนัก **≥ 3.00** → **มีนัยสำคัญ**
3. **กฎบังคับ**: หมวดที่ Magnitude **≥ T** ถือว่ามีนัยสำคัญเสมอ แม้คะแนนรวมจะไม่ถึง 3.00 (สอดคล้องกับ GHG Protocol ที่ให้ขนาดการปล่อยเป็นเหตุผลเพียงพอในการรวมหมวดนั้น)

## 5. การบันทึกลงแบบฟอร์ม Excel

| คอลัมน์ | สิ่งที่ระบบเขียน |
|---|---|
| C | ติ๊ก (Wingdings 2 = "P") เมื่อผลประเมินคือ *มีนัยสำคัญ* |
| D | % ของ Scope 3 ทั้งหมด (สัดส่วนจริง) |
| E, F, H | ระดับคะแนนแปลงเป็น % ของคะแนนเต็ม — 1 = 20%, 2 = 40%, 3 = 60%, 4 = 80%, 5 = 100% |
| K, N | ติ๊กเมื่อได้ระดับ **≥ 4** |
| O | หมายเหตุของผู้ใช้ ถ้าเว้นว่างระบบเขียนสรุป เช่น `คะแนนถ่วงน้ำหนัก 3.40/5.00 — มีนัยสำคัญ` |
| ใต้ A35 | คำอธิบายเกณฑ์ทั้งชุด (น้ำหนัก ช่วงคะแนน กฎการตัดสิน) เพื่อให้ผู้ทวนสอบเห็นที่มา |

## 6. ข้อควรระวัง

- เซลล์ E, F, H เป็นรูปแบบ `0.00%` ต้องเขียนเป็นสัดส่วน (ระดับ 4 → 0.80) ห้ามเขียน 80 ตรง ๆ
- ช่องติ๊ก C, K, N ใช้ฟอนต์ Wingdings 2 ต้องเขียนอักขระ `"P"` เท่านั้น ห้ามใช้ `✓`
- น้ำหนักทั้ง 6 ข้อต้องรวมได้ 1.00 เสมอ ถ้าแก้ค่าใดต้องปรับข้ออื่นชดเชย มิฉะนั้นคะแนนเต็มจะไม่เท่ากับ 5.00
- ถ้าองค์กรต้องการน้ำหนักชุดอื่น ให้แก้ค่าคงที่ใน `CfoReportService.Fr032Rubric` ที่เดียว ทั้งหน้าจอและไฟล์ Excel จะเปลี่ยนตามพร้อมกัน
